# Snowball (Snowcraft)

Gra na telefon w przeglądarce: rzucasz śnieżkami w drużynę przeciwników sterowaną przez komputer. Inspirowana klasyczną grą Snowcraft z 1998 r., z własną grafiką. Czysty HTML, CSS i JavaScript, hosting GitHub Pages. Gra się w poziomie, dwoma palcami: joystick po prawej, drugi palec celuje i rzuca.

Dokumentacja: `docs/` (mapa dokumentów w `docs/INSTRUKCJA_WDRAZANIA.md`). Instrukcje dla agenta: `CLAUDE.md`.
